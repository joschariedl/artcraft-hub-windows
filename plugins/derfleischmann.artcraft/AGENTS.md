# AGENTS.md — derfleischmann.artcraft

Notes for AI agents working on this plugin. The plugin is shipped as part of
the `artcraft-hub` repository (https://github.com/joschariedl/artcraft-hub),
not as a standalone repo.

## Repository workflow

This plugin lives in the `artcraft-hub` repository. Any change made here must
be committed, pushed to that repository, and merged into the default branch
(`main`) automatically — do not leave changes uncommitted or only local.
